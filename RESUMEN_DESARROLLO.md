## ⚙️ FUNCIONALIDADES TÉCNICAS

### LOCALSTORAGE:
```javascript
Key: 'lordsmobile_custom_teams'
Formato: {
  "MonsterName-type-level": ["Hero1", "Hero2", "Hero3", "Hero4", "Hero5"]
}
Ejemplo: {
  "Abeja Reina-f2p-level1-3": ["Cuervo Negro", "Matademonios", ...]
}
```

### EXPORTAR:
- Convierte customTeams a JSON
- Crea Blob y descarga como `lordsmobile_config.json`
- Alert confirmación

### IMPORTAR:
- Input file (accept .json)
- FileReader lee contenido
- Parse JSON y sobrescribe customTeams
- localStorage.setItem
- Alert confirmación
- Renderiza de nuevo

### RESETEAR:
- Confirm dialog
- customTeams = {}
- localStorage.removeItem
- Alert confirmación
- Renderiza de nuevo

### PROTECCIÓN ANTI-COPIA:
```javascript
- contextmenu → preventDefault
- keydown → bloquea F12, Ctrl+Shift+I, Ctrl+U, Ctrl+S, Ctrl+C
- user-select: none (CSS)
- Copyright en footer: "© Lords Mobile Hunting Guide - by knayus"
```

### CONVERSIÓN NOMBRES:
```javascript
function heroToFilename(name) {
  return name.toLowerCase()
    .replace(/ /g, '_')
    .replace(/á/g, 'a')
    .replace(/é/g, 'e')
    .replace(/í/g, 'i')
    .replace(/ó/g, 'o')
    .replace(/ú/g, 'u')
    .replace(/ñ/g, 'n');
}
```
