# 🏰 Lords Mobile - Guía de Cacería de Monstruos v1.0

Aplicación web (PWA) completa para consultar equipos de héroes y drop rates de los 25 monstruos de Lords Mobile.

## 📱 Características

- ✅ 25 monstruos (24 normales + Caballero Fantasma)
- ✅ 57 héroes (20 F2P + 4 Evento + 33 P2P)
- ✅ Equipos predefinidos por nivel (1-3, 4, 5)
- ✅ Equipos personalizables guardados localmente
- ✅ Drop rates con porcentajes
- ✅ Sistema import/export de configuración
- ✅ Diseño responsive
- ✅ Funciona offline (PWA)

## 🚀 Uso

1. Abre `index.html` en tu navegador
2. Selecciona un monstruo
3. Consulta equipos F2P y P2P por nivel
4. Personaliza tus equipos favoritos
5. Exporta/importa tu configuración

## 📊 Estructura

- **index.html** - Aplicación completa (267KB)
- **manifest.json** - Configuración PWA
- **img/monstruos/** - 25 imágenes .webp
- **img/heroes/** - 57 imágenes .webp
